# ZeJi-market-review｜研究与核验规则

本文件是按用户要求补充的工作说明，不是Zeji公开的参数或经过回测的交易规则。目的在于减少漏看、核实依据、区分事实与判断。这里的数量和窗口是可调整的工作默认值，不声称能提高收益。

## 1. 数据与时间

### 最小资料清单

| 用途 | 需要的资料 | 拿不到时怎么处理 |
|---|---|---|
| 市场范围 | 交易日历、行业分类清单、版本及成分日期 | 不能确认交易日或覆盖分母时明确标记 |
| 行业扫描 | 同一来源的行业指数或成分集合，日价格、成交、可交易成员数 | 报告覆盖到的范围，不声称已扫全市场 |
| 变化与持续性 | 对齐的1、5、20个交易日记录 | 缺多少就标多少；单日不能写持续改善 |
| 业务核验 | 公司公告、定期报告、公开经营资料 | 只列待核实公司，不凭概念标签入池 |
| 行业逻辑 | 供需、价格、订单、经营、政策或事件原始资料 | 给出具体缺口，不能把传闻升级为确定事实 |
| ETF观察 | 产品身份、跟踪对象、份额、净值、持仓或申赎清单及各自日期 | 无份额不估申赎；无纯度不推断细分行业资金 |
| 用户对照 | 关注列表、已有候选池、持仓及规则（可选） | 不妨碍研究；无法对照时不宣称“你遗漏了” |

每个来源留一行记录：编号、发布主体、资料标题、URL或文件位置、事件／数据日期、发布时间、获取时间、支持哪条结论。关键事实旁放来源编号；外部原始链接放来源表。用户材料没有原始出处时注明“用户材料、未独立核实”。

当期复盘先实际取资料。历史复盘按当时可获得信息重建；成分、财报和研报的“所属时期”不等于“当时已经公开”。盘中成交只能与同一时段比较，不能直接与完整交易日比。海外收盘按真实发生时间进入信息截止范围，不能只按日期字符串对齐。

资料冲突先检查日期、单位、复权、成分调整及统计口径。冲突无法消除时呈现差异，不挑选最符合自己观点的数值。受限材料、隐藏付费全文、未经实际访问的页面不能作为已读取事实。

### 数据来源顺序

市场及产品制度优先核对交易所、基金管理人及具体法律文件；公司业务优先公告和定期报告；行业变化优先统计部门、行业组织和明确样本的原始数据。可核验行情服务用于价格和成交，写明提供方与口径。研报属于研究观点，新闻转载回溯原始发布，社交消息仅作检索线索。

本技能不绑定固定数据商或接口。宿主有数据连接、文件检索和网页检索时按实际能力调用；没有就明确限制，不虚构联网、抓取成功或行情接口。不要为获取数据请求账户密码。

## 2. 先独立发现，再做个人对照

### 第一轮：形成独立候选初表

先读取行业分类清单和市场数据。即使用户已给自选，第一轮也不据此限定搜索、删掉不熟悉行业或给熟悉行业加分。保存当时初表与选择依据，再开展个人对照。此顺序只能降低选择偏差，不等于模型真的没有见过用户偏好。

基础扫描覆盖同一分类中的全部一级行业，尽可能覆盖二级行业；若二级只展开少数方向，必须另外报告。主题作为补充，不是完整行业分类的替代。行业和主题成分重叠，不能直接相加成为市场总量。

同时建立两份线索：

**市场先行线索：** 从完整强弱表中找持续强势、开始增强、低位异常及高位转弱。不能只保留当日涨幅前几名。

**逻辑先行线索：** 在分类清单上检查新披露经营、供需、价格、政策或事件变化，专门查看市场尚未明显响应的方向。未检索到资料不等于该行业无变化；单列未深入检索的行业。

无需声称每天阅读全部上市公司公告。区分“行业行情覆盖”“行业逻辑资料覆盖”和“重点公司深查”，各自报告范围。

### 覆盖记录

| 层次 | 分类／来源／版本 | 应检查数 | 有效检查数 | 缺失或未展开 | 数据日期 |
|---|---|---:|---:|---|---|
| 一级行业行情 | … | … | … | … | … |
| 二级行业行情 | … | … | … | … | … |
| 主题补充 | … | 若无完整母表则未知 | … | 不宣称穷尽 | … |
| 行业逻辑资料 | … | …或范围未知 | … | … | … |

有效覆盖率＝有效检查数÷已知应检查数；分母未知则覆盖率不可计算。行数齐全但关键数据缺失，不算该项有效覆盖。上级行业完整不代表二级完整。只有部分榜单或几篇报道时，一律称“部分扫描”。

### 全量扫描记录最小字段

日期、分类及层级、板块代码／名称、成分口径、1/5/20日涨幅及相对表现、成交变化、上涨覆盖面、数据状态、来源编号、入选或未入选的原因。

完整表可另存或作为附表；没有持久写入能力就输出可复制记录，不宣称已经保存。发现类结果可以为空。

## 3. 指标口径：用于找线索，不是买点公式

默认窗口可调整，但一次对比内保持一致。需要计算时实际计算并抽样复核；没有原始值不能凭印象填历史排名或分位。

| 指标 | 定义与注意事项 |
|---|---|
| n日涨幅 | P(t)/P(t−n)−1，n取1、5、20个交易日；股票按一致复权口径，指数按一致价格／全收益口径 |
| 相对市场表现 | 板块n日涨幅−明确宽基的同期涨幅，单位为百分点；它不是净流入 |
| 成交活跃倍数 | 当日成交额÷此前20个完整交易日平均成交额，不含当日；不足20日标不可计算，除非明确改用更短窗口 |
| 成交占比 | 该板块去重成员成交额÷同日同市场统计范围总成交额；比较此前5日平均占比，单位变化为百分点 |
| 上涨覆盖面 | 上涨的可交易成员数÷当日有效可交易成员数，列出分子和分母；停牌、数据缺失的处理要一致 |
| 扩散与持续性 | 比较多个交易日参与股票数量、等权表现或中位数，检查是否只有一两只大权重推动 |
| 位置与拥挤 | 明确窗口内的累计涨幅、回撤、参与集中度和交易活跃变化；高低位要有比较对象，不直接推定便宜昂贵 |

涨幅公式中的“−1”指比值再减去1，不是将时间下标多减一天。例如5日涨幅＝P(t)/P(t−5)−1。所有比例分母为0或数据不足均为不可计算，不能补0或跨停牌日向前填充成交。

不必每次凑齐所有指标，但评为“市场初步认可”至少需要不止单日的价格信号和另一类参与信号；缺关键项时保留不确定性。一个数据源可以支持多项观察，但不同价格变形指标不能伪装成独立证据。

## 4. 资金与关注度：哪些能说，哪些不能说

价格与成交用于描述交易行为；ETF份额用于描述某个产品份额的净变化。行业涨跌、市场资金身份、ETF申赎，是不同的问题，不能相互替代。

需要估算ETF净申购对应金额时，可在口径一致且剔除份额折算等影响后使用：

**估算的净新增份额价值＝（当日份额−前日份额）×当日单位净值。**

这只是一种近似计值，不是精确投资者现金净流入，不包含全部场外或行业资金，也不证明特定投资者看多。采用其他净值日期必须说明。多日估算逐日算后相加；缺净值或份额就不算。多产品汇总列明产品集合，避免重复统计，不把同一宽基重复分配到多个行业。

ETF优先选与研究方向直接对应的产品；没有时可使用较宽行业产品，但显著标注“宽口径代理”、成分相关度和不能解释的细分部分。相关度用可核验的成分及其权重说明；只有前十大持仓时，只能说明已披露部分，不把它当成完整组合纯度。基金规模受价格变化影响，不能用规模增加直接替代申购；二级市场成交不是一级市场申赎。[W02、W03；来源清单见source-map.md]

行情商“主力净流入”等分类指标只作为该提供方口径的数据，注明定义局限，不能写成真实机构账户流量。仅有价量时，推荐用语是“交易关注度上升／板块参与增强”。

### 轮动记录必须完整

原方向：____；新方向：____；共同观察期间：____。

事实：两边相对走势、成交占比、参与范围的变化分别是____。

假设：可能出现____，原因是____。

替代解释：也可能是全市场扩张／指数权重影响／单家公司事件／同一宏观因素／其他____。

下一项验证：在____期间观察____；不成立条件是____。

置信表述：有线索／多项支持／仍不足；不得给无依据的胜率。

两个方向同时增强时不强行写成“从A撤出进入B”。产业链次序、海外映射及ETF共同成分，只建立候选关系，不证明资金因果。

## 5. 逻辑与市场认可的判定标准

### 逻辑

| 状态 | 判断依据 |
|---|---|
| 强 | 关键业务关系清楚，原始经营／供需资料支持核心机制，并解释主要反证；不意味股价便宜 |
| 中 | 业务和机会有依据，但规模、兑现时间、盈利改善或竞争结果仍不确定 |
| 弱 | 已有材料与主要论点冲突，或实际关联很弱；应说明是哪条证据，不因个人不熟悉就判弱 |
| 未知 | 不足以判断；先补资料，不硬给分 |

政策、行业景气、公司受益、收入和利润须逐层连接。只证明“政策支持AI”，不足以证明某公司将获订单。竞争、客户集中、现金回收、执行和估值透支等反面信息也要查。

### 市场认可

| 状态 | 判断依据 |
|---|---|
| 未确认 | 有可用观察期数据，但尚未出现相对增强与参与扩散；不是因为没拿到数据 |
| 初步认可 | 不止单日的相对改善，并有成交参与或多股扩散的支持；观察期仍短、尚待继续验证 |
| 持续认可 | 相对强势和较广参与在更长窗口延续，或经调整后仍有支持；注明实际窗口，不能只说“公认主线” |
| 转弱 | 之前有认可证据，现在相对表现、参与或持续性同步恶化；没有前期记录就不要编“退潮” |
| 证据不足 | 缺历史、缺有效样本、信息冲突或只有一天异动 |

这是结构化判断，不是固定量化交易信号。不设置凭空的“逻辑87分、胜率75%”。初步认可不等于即将上涨；持续认可不等于应当追买。

### 组合后的研究顺序

逻辑强／中＋初步认可：优先研究，但继续检查价格、风险及反证。

逻辑强／中＋未确认：保留逻辑先行名单，写等待什么，不用“确定补涨”。

逻辑强／中＋持续认可：跟踪已有方向，单独检查是否已交易充分。

逻辑弱／未知＋强势市场：情绪观察，业务补证之前不得写成基本面低估。

逻辑转弱或市场转弱：复查原假设；已有持仓优先核查风险，不能简单一律加仓摊薄。

## 6. 新发现与股票池

### 独立证据与关注盲区

重点新增研究需至少一类原始产业证据和一类多股／持续市场证据，且来自不同事实基础。两个网站转载同一消息算一条；1日涨幅、5日涨幅和同一涨势相关新闻不算三条独立证据。

只有经营逻辑但未获市场认可的方向，放“逻辑先行、等待确认”；只有单日异动的放“市场线索、待核实”。它们也属于主动发现，不因为未达到重点研究门槛而丢弃，但不能与双重确认项混列。

对照用户列表时先处理别名和层级，例如宽泛化工与某细分材料不一定完全相同。标明“原关注中的新细分”或“完全新增方向”，不能为凑发现数重复命名。没有用户列表时统一称独立补充观察。

### 股票角色与阶段

角色：市场核心需相对走势及参与度依据；业务直接需披露依据；弹性观察需波动／敏感性依据；低位观察需定义窗口及业务依据。无需四种角色齐全，一只可兼多种角色。

阶段：

| 阶段 | 进入条件 | 下一步 |
|---|---|---|
| 待核实 | 来自扫描的线索，但身份、业务或核心资料不足 | 查清缺口；不列为正式观察股 |
| 研究 | 身份、业务关系已确认，尚在验证逻辑或市场 | 补反证、市场持续性或价格资料 |
| 观察 | 业务确认、逻辑非明显冲突，且有多于单日的市场支持 | 跟踪验证条件；不自动代表可以买 |
| 预案 | 上述检查通过，并有价格风险判断、走势条件和用户约束 | 形成待本人确认的条件—动作计划 |
| 降级／移出 | 新证据削弱理由、条件失效、范围不适合或长期缺资料 | 写原因和复查条件，保留历史记录 |

逻辑未知但市场强的个股可以列情绪观察专栏，不绕过业务核验，也不进入本技能的常规新增交易预案。用户明确要求纯情绪策略时另定规则，不在这里暗中切换。

观察股不要求必须算出目标价。进入新增买入预案时，至少要有透明的价格／风险边界；若不能估值，必须明确标注依据不是“低估”。缺账户限制时输出市场观察触发，不伪造仓位计划。

### 维护与存档

主键采用交易所＋证券代码；保存多个板块标签，但只占一条主记录。缺数据的持仓留在持仓风险表，不从表中消失。新增、升级、降级、移出都需日期、依据及来源，移出不等于立即卖出。

在获得文件写入授权时，可在用户指定工作目录保留日期化记录：复盘、独立扫描、板块池、股票池、变化记录与资料表。不得修改技能模板本身来代替保存日报。没有写入能力时交付完整可复制文本，明确尚未持久保存。

## 7. 估价、映射及行动限制

估值只服务于关键候选，不给15只股票批量编目标价。任何公式列出输入及出处；公司规模、业务纯度、利润率、成长和风险不同，不能机械复制同行倍数。区间和情景比单点更适合表达不确定性，但也不能凭空编区间。

跨市场核实收盘时间差、汇率、业务和估值口径；涨跌幅制度、交易权限和ETF具体规则按产品及当期官方说明另行核查。[W02–W04] 不在本文件写死某产品的涨停比例，也不保证折价会在下一交易日兑现。

每个交易预案应可观察、可取消，并先检查用户风险限制。无融资且账户只含股票和现金时，逐情景核对股票比例＋现金＝100%；其他账户结构按实际口径。行情变化后要重新算；涨跌停或停牌可能使计划无法成交，不能把预定退出价当实际损失上限。

不猜主力意图，不依赖未公开消息，不鼓励用加杠杆弥补错过行情。复盘只交付研究和本人确认的计划，不自动交易。

## 自主查询与出处

按[工具池](tool-pool.md)先检查环境、确定日期、扫描，再补证公司与产业资料。来源故障最多重试两次，访问受限停止该路线。备用来源必须验证目标日期及历史窗口；非空旧数据不能阻止尝试备用。申万与东方财富分类分开列示。原文入口页面与附件正文分开核验，休市期间公告查至信息截止日。行情收盘时点、海外当地日期、统计单位与重复记录在使用前检查。

最终报告附sources、coverage、候选变化及实际阅读记录。核心市场或行业行情缺失时必须标为部分可用，即使能写出文章也不能判定完整通过。
