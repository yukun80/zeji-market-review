# ZeJi-market-review

**先发现自己没注意到的市场变化，再研究股票，最后写下一交易日预案。**

这是根据Zeji的直播做法和后续补充要求重写的复盘技能包。它不只检查你已经关注的板块，也要求AI主动扫描可获得的全市场资料、发现新方向、查公司并维护候选池。具体效果取决于实际数据和运行工具，不保证发现上涨机会。

## 新版怎样工作

市场环境 → 独立扫描全市场 → 资金与关注度变化 → 逻辑与市场认可分开验证 → 板块池与关注盲区 → 主动建立股票池 → 映射核验 → 价格判断 → 走势与持仓 → 条件—动作预案。

最重要的顺序变化是：先形成独立候选，再对照你的自选。关注列表是对照材料，不是市场扫描的边界。候选并非全部涨得最多的股票，还包括逻辑有改善但市场尚未回应的方向。

股票池区分待核实、研究、观察、预案。知道名字不等于查过业务，查过业务不等于适合买入。没有完整资料时，保留线索和缺口，不为凑数量造机会。

## 给AI使用

支持技能目录的工具：把完整的 `zeji-market-review` 文件夹交给该工具的技能加载功能，保留子目录。安装方法按使用工具自己的说明执行；本包不假定某一平台的专用安装路径。

普通聊天工具：提供完整技能包；不能读取压缩包时，分别提供SKILL.md、研究与核验规则，以及你要用的模板。首次使用可同时提供来源说明。只粘贴一句调用话语，不能替代技能文件本身。

显示名是 **ZeJi-market-review**；为了符合Agent Skills文件格式约定，安装目录与内部名称采用小写 **zeji-market-review**。二者指同一个包。[格式依据见来源说明W01]

### 主动复盘调用示例

> 使用ZeJi-market-review做____年__月__日A股收盘复盘，信息截至北京时间____。请先独立扫描行业与主题，再对照我的关注列表，主动发现值得新增研究的方向并建立候选股票池。允许检索公开资料；注明覆盖范围、来源和时间。请输出三句话简版、每日标准版及股票池变化；不能确认的地方明确写出。
>
> 我的关注列表是____（可不填）。旧股票池是____（可不填）。持仓、现金和限制是____（可不填）。没有账户资料时，请完成市场研究，但不要擅自设定调仓比例。

### 没有特别关注方向

> 使用ZeJi-market-review复盘最近一个已完成的A股交易日。我没有指定板块，请独立扫描，不要默认只看科技。分别给出已经很强、正在增强、转弱、低位异常，以及逻辑改善但尚未被市场认可的线索；查证后给少量候选。没有全量数据就说明覆盖范围，不要假装全市场扫描已经完成。

### 仅使用已有材料

> 使用ZeJi-market-review，只分析本次附件，信息截止____，不要添加外部资料。请在材料覆盖范围内发现新线索、检查逻辑与市场表现并形成候选。明确哪些发现和判断因为缺资料不能完成。

### 周末研究

> 使用ZeJi-market-review周末研究版。根据本周复盘和股票池，选择一个值得补课的新方向，核对业务、反证和市场认可，更新候选阶段，并列出下周只需要继续观察的变化。

## 自己填写

打开每日模板，先写日期、范围和数据，再依次填写十步；完成后回到最上方写三句话。行情扫描结果和公司资料可以由AI先整理，你主要核对个人规则、持仓和实际操作，再决定是否采用任何预案。

长期公司记录放在股票池模板里；每日只写变化，不从头抄一遍公司简介。周末补充陌生板块的研究。没有新方向可以写无，没有交易可以写不行动，这些都是有效结果。

获得文件保存能力时，另建日期化日报和池记录，不直接覆盖本包空白模板或旧计划。没有保存能力则保留输出文本；技能本身不会自动记住未保存的历史。

## 能力与限制

本包是工作要求与模板，不附带实时行情接口，不在后台自动扫描，也不会自动下单。完整主动复盘需要可用的行业数据、公开资料和检索能力；只有几个截图时只能做部分研究。

原文不是完整交易系统。本次没有复现发言人的收益、没有实际市场选股回测，也没有验证在某个聊天工具中的自动调用效果。原文、后续扩展和外部规则核对在来源说明中分别列出。
